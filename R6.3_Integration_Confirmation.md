### ✅ 3. Exact Microcode Capture Code

**Integrated in**: Section B1

```python
def read_microcode():
    values = []
    with open("/proc/cpuinfo") as f:
        for line in f:
            if line.startswith("microcode"):
                _, val = line.split(":", 1)
                val = val.strip()
                if val:
                    values.append(val)
    if not values:
        raise GovernanceError("Unable to capture CPU microcode")
    return "|".join(sorted(set(values)))
```
