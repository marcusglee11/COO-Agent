BLOCKING FIX B1 — REAL CRYPTOGRAPHIC SIGNATURES
==========================================
Requirement

Replace mock signatures (SIG_<digest>_CEO_KEY) with real signature verification using Ed25519.

Implementation Requirements

Add new file: coo_runtime/util/crypto.py
Implement:

from nacl.signing import VerifyKey, SigningKey

def sign_bytes(private_key_path: str, data: bytes) -> bytes:
    sk = SigningKey(open(private_key_path, "rb").read())
    return sk.sign(data).signature

def verify_signature(public_key_path: str, data: bytes, signature: bytes) -> bool:
    vk = VerifyKey(open(public_key_path, "rb").read())
    try:
        vk.verify(data, signature)
        return True
    except Exception:
        return False


No mocks, no bypass.

Modify AMUCapture._sign_amu0()

Load CEO private key from manifests/ceo_private_key.pem

Generate canonical AMU0 hash: hashlib.sha256(<all files in sorted order>)

Save signature to: amu0_capture/signature.sig (raw bytes)

Modify RollbackEngine._verify_amu0_signature()

Load CEO public key from manifests/ceo_public_key.pem

Reject (GovernanceError) if signature missing or invalid

No DEV-mode bypass allowed

STRICT_MODE does not change signature logic

Signature verification always required

DEV mode must behave identically for signature verification

def apply_pinned_context(pinned_context_path: str):
    ctx = json.load(open(pinned_context_path))

    # 1. RNG
    random.seed(ctx["rng_seed"])

    # 2. ENV VARS (replace all non-allowed vars)
    os.environ.clear()
    for k, v in ctx["env_vars"].items():
        os.environ[k] = v

    # 3. Mock time (STRICT mode only)
    if ctx.get("mock_time") is not None:
        os.environ["FAKETIME"] = ctx["mock_time"]  # for libfaketime
